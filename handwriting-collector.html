Stroke file

Export creates a v2 JSON file with one entry for every requested glyph. Letters and digits may have up to three samples; use Add variant after drawing the first. Import v1 files without recollection; keep your original export as a backup. Coordinates are normalized so the baseline is y = 0 and positive y points upward. Each entry contains its stroke list and ink bounding box. Skipped or empty entries are included and marked missing, so an incomplete file is detectable later.

What is not collected?

Braces, brackets, bars, and angle delimiters are omitted because they need to scale around fractions and roots. Parentheses can be collected; draw each around a capital-height glyph, from above the upper guide to just below the baseline. The renderer stretches them vertically to fit their contents. Fraction bars, radical bars, accent strokes, and other layout primitives are also not separate prompts. Named operators such as sin and lim are composed from the collected Latin letters. Equivalent LaTeX command aliases share one visual sample; the exported entry records those aliases.
